# Sadik Ali - Software Developer Portfolio

A responsive portfolio built with plain HTML, CSS, and vanilla JavaScript. It has no frontend package dependencies or build step, so it can be served directly as a static site on Netlify.

## Run locally

From this directory, start Python's built-in static web server:

```bash
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). If Python is not installed, any static file server can serve this directory.

## Deploy to Netlify

The included `netlify.toml` publishes the repository root directly. Connect the GitHub repository to Netlify and deploy without a build command. The `/resume` route renders a print-friendly resume; use **Save as PDF / Print** in the browser to download it.

## Technologies

- Portfolio website: HTML, CSS, and vanilla JavaScript
- Developer skills featured: Python, Java, JavaScript, SQL, and web development
- Hosting: Netlify static hosting
